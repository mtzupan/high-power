# Project

Documentation structure for the Wind Turbine project.

The information in this folder is generally populated from Confluence & other online collaboration tools. 

The purpose 

| #   | Folder                                                                    | Purpose                                                                                 |
| --- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 01  | [Charter and Scope](01 - Charter and Scope)                               | Problem statement, objectives, in/out of scope                                          |
| 02  | [Schedule](02 - Schedule)                                                 | Timeline, milestones, Gantt exports                                                     |
| 03  | [Staffing Plan](03 - Staffing Plan)                                       | Which of the 15 resources are allocated, % time, matrix approvals from functional leads |
| 04  | [Budget and Finance](04 - Budget and Finance)                             | Cost estimates, actuals, POs                                                            |
| 05  | [Risk and Issues Register](05 - Risk and Issues Register)                 | Risk log, mitigation plans, open issues                                                 |
| 06  | [CAD and Engineering Files](06 - CAD and Engineering Files)               | Design files, drawings, revisions                                                       |
| 07  | [Procurement and Vendors](07 - Procurement and Vendors)                   | Supplier quotes, contracts, PO tracking                                                 |
| 08  | [Manufacturing and Quality](08 - Manufacturing and Quality)               | Build plans, QA/QC records, specs                                                       |
| 09  | [Shipping and Receiving](09 - Shipping and Receiving)                     | Logistics, packing lists, delivery tracking                                             |
| 10  | [Testing and Validation](10 - Testing and Validation)                     | Test plans, results, certifications                                                     |
| 11  | [Meeting Notes and Communications](11 - Meeting Notes and Communications) | Status updates, stakeholder comms                                                       |
| 12  | [Closeout and Lessons Learned](12 - Closeout and Lessons Learned)         | Retro, handoff docs, archive                                                            |
